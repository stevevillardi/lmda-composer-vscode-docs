## [Unreleased]

### Added

- [Script Lint](/lmda-composer-vscode-docs/features/script-lint/) documentation — PropertySource naming, BatchScript patterns, PowerShell output, and property token validation (based on [monitoring-recipes](https://github.com/logicmonitor/monitoring-recipes) best practices)

## [0.1.2] - 2026-08-24

### Added

- Documentation site with installation, quick start, features, settings, and troubleshooting guides
- Walkthrough steps link to the documentation site

### Changed

- Marketplace README streamlined; full guides live on the documentation site
- Screenshots served from the documentation site

### Fixed

- Switching portals clears the previous collector and device selection instead of re-applying a stale default collector

## [0.1.1] - 2026-08-24

### Fixed

- Marketplace screenshots load from the public documentation site
- Removed private repository links from marketplace resources

## [0.1.0] - 2026-08-24

### Added

- Connect LogicMonitor portals and choose a collector and device for each project
- Run Groovy and PowerShell scripts on collectors with live output and Problems validation
- Browse LogicModules, load scripts, and open modules in LogicMonitor
- Get Started walkthrough and sidebar guidance
- Inline Run, Push, and Open actions above scripts
- Execution history to replay recent runs
- Push script changes with visual diff review and optional audit reason
- Snippets and diagnostics for `##TOKEN##` placeholders
- Collector and device pickers for large portal inventories
