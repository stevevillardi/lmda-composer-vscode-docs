---
title: Troubleshooting
description: Common issues and how to fix them.
---

**Connection or permission errors** — Run **LMDA: Update Portal Bearer Token** to refresh credentials. Reinstalling the extension or changing publisher may require reconnecting your portal.

**LMDA sidebar looks inactive** — Open a `.groovy` or `.ps1` file first so the extension activates.

**PowerShell script fails** — Select a **Windows** collector.

**Untrusted workspace warning** — Trust the folder before running scripts or saving tokens.

**Groovy opens as Plain Text** — Install **code-groovy** or set `"files.associations": { "*.groovy": "groovy" }`.

[Open an issue](https://github.com/stevevillardi/lmda-composer-vscode-docs/issues) or email steven.villardi@logicmonitor.com.
