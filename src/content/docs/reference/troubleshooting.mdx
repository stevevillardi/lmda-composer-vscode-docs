---
title: Troubleshooting
description: Common issues.
---

**API failures** — **LMDA: Update Portal Bearer Token** (reinstall/publisher change requires reconnect).

**Sidebar inactive** — Open `.groovy` or `.ps1` first.

**PowerShell fails** — Use a **Windows** collector.

**Untrusted workspace** — Trust the folder before runs/tokens.

**Plain Text Groovy** — Install **code-groovy** or `"files.associations": { "*.groovy": "groovy" }`.

[Open an issue](https://github.com/stevevillardi/lmda-composer-vscode-docs/issues) or email steven.villardi@logicmonitor.com.
