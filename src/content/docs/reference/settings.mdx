---
title: Settings
description: Configuration reference (`@lmda`).
---

| Setting | Purpose |
| --- | --- |
| `lmda.defaultPortalId` | Portal for this window |
| `lmda.defaultCollectorId` | Default collector (`0` = prompt) |
| `lmda.defaultDeviceHostname` | Device for tokens / hostProps |
| `lmda.executionMode` | `freeform`, `ad`, `collection`, `batchcollection` |
| `lmda.defaultLanguage` | New untitled script language |
| `lmda.enableModuleLint` | Token/mode diagnostics |
| `lmda.focusOutputOnRun` | Focus Output on run |
| `lmda.executionHistory.enabled` | Record runs for replay |
| `lmda.executionHistory.maxEntries` | History size (1–200) |
| `lmda.codeLens.enabled` | Inline Run/Push/Open actions |

Tokens: Secret Storage. Hostnames: settings.
