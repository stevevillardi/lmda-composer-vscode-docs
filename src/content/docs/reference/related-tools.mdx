## LMDA Composer — Chrome extension

[Chrome Web Store](https://chromewebstore.google.com/detail/lmda-composer-logicmodule/bopacknfeabibohddhdakmlmfekijbea) — browser-based IDE with module browsing, script execution, API Explorer, and collector sizing. [Docs](https://stevevillardi.github.io/lmda-composer/)

## Logic.Monitor — PowerShell

[PowerShell Gallery](https://www.powershellgallery.com/packages/Logic.Monitor) — `Install-Module -Name Logic.Monitor` for portal automation from the command line.

These are community projects and are not official LogicMonitor products.
