## 1. Add portal

**LMDA: Add Portal** — hostname (e.g. `acme.logicmonitor.com`) and Bearer token. Tokens use Secret Storage.

## 2. Select collector

**LMDA: Select Collector** — Groovy: Linux or Windows; PowerShell: **Windows only**.

## 3. Open a script

Walkthrough sample, local `.groovy`/`.ps1`, or load from **LogicModules**.

## 4. Run

`Cmd+Alt+R` / `Ctrl+Alt+R`, editor **Play** icon, or **LMDA: Run Script**. Output in **LMDA Composer** channel.

<Aside type="note">Set **Mode** in the status bar for AD/collection Problems parsing.</Aside>
